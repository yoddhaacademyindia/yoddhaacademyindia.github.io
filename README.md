## 🌟 प्रमुख फिचर्स:

1. **AI कॅमेरा व्हिजन ट्रॅकिंग (Live Pose Scoring):**
   - कॅमेऱ्यासमोर विद्यार्थी उभा राहून लाठी फिरवतो.
   - AI सिस्टीम लाठीची पकड, संतुलन, फिरकीचा वेग आणि अचूकता तपासून Grade A, B, C, D देते.
2. **२४ तासांत डिजिटल प्रमाणपत्र (QR Verified Certificate):**
   - विद्यार्थ्याचे नाव, युनिक ID, उत्तीर्ण लेव्हल आणि ग्रेडसह सोनेरी बॉर्डर असलेले अधिकृत प्रमाणपत्र मिळते.
   - एका क्लिकवर PDF किंवा कलर प्रिंट काढता येते.
3. **एका क्लिकवर Level Up:**
   - परीक्षा पास झाल्यावर "Level Up" बटण सक्रिय होते. 
   - त्यावर क्लिक करताच विद्यार्थी पुढच्या लेव्हलमध्ये जातो आणि त्याचा पुढचा ४ महिन्यांचा सिलॅबस सुरू होतो.
4. **Google Sheets ऑटो-सिंक:**
   - सर्व डेटा गुगल शीटमध्ये सुरक्षित साठवला जातो.
5. **YouTube Unlisted सिलॅबस:**
   - ० MB सर्व्हर स्टोरेज. अनलिमिटेड मोफत स्ट्रीमिंग.
